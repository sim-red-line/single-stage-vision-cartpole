## Homing abort behavior

In the currently installed firmware, ordinary `STOP` zeros the target but does
**not** leave the homing state machine; the next update can restore the homing
velocity. `ESTOP` is required to abort an active home. The temporary supervised
home helper was corrected to use `ESTOP` on an unsuccessful exit while homing
remains active. The successful final centered state was not emergency-stopped
or unhomed. No firmware change was flashed.
